# 2026.294.1518 — fix(pipeline): resolve `${env.NAME}` in a data string — both spellings, the real map, a named miss

## Summary

A pipeline **data** field naming an environment value had no resolver at HEAD, in three
independent ways — and `plugin-migrate`'s reshape emits exactly that spelling, so a migrated
entity's `corpus`, `cache.key` and `vars.sha` / `emit` `head:`+`sha:` leaves reached a verb body
as **literal text**.

| what was wrong | where | what it is now |
|---|---|---|
| the grammar matched the BARE form only | `refs.go:27` — `\$env\.([A-Z0-9_]+)` | `envRefRe` admits `$env.NAME` **and** `${env.NAME}` (`refs.go:23`), split from `runRefRe` (`refs.go:31`) |
| `resolveRefs` returned the text verbatim under the standalone IDENTITY resolver | `refs.go:37-39` | the ENVIRONMENT namespace is substituted **before** the override (`refs.go:56`), because nothing else in the chain resolves it |
| the only production constructor left the map nil | `verb_env.go:65` `standaloneVerbEnv` | `procEnv: envMap()` — `os.Environ()`, the source the retired `$env.NAME` read (`verb_env.go:103`) |
| a missing name read `""` | `refs.go:56` | recorded during resolution, reported as **one named failure** of the whole dispatch (`verb_env.go:216`) |
| a shell field would take a value as script text | `render.go:31` (`exec.Command("bash","-c",cmd)`) | `validate:` **refuses** an env ref and names the shell's own `${NAME}` (`render.go:42`) |

### Missing variable: a NAMED error, deliberately

Empty is a run-time emptiness in place of a load error — a cache key that never matches, an
emitted record carrying `head: ""` — the same trade `opencharly/sdk#443` refused for the knob
form. The names are collected during resolution and reported once, aggregate, prefixed to any
downstream error so a real failure is never hidden behind the miss.

### What this does not do, with the owner named

  `rc.skills` has no writer in the package — that is **plugin-pipeline#37** (evidence added
  there). This change makes that ref RESOLVABLE; #37 makes it REACHABLE. Half-wiring the knob
  from `raw["skills"]` here would collide with #37's chosen dispatcher-level repopulator.
- **The publish gate's `skip_when` to `when:` stays `opencharly/sdk#443`'s** (the expression

  have helped. `${env.NAME}` is now both the spelling that resolves AND the one the expression
  grammar accepts, so the reshape's output stays as it is.
