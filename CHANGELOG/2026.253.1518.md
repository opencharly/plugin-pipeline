# 2026.253.1518 — fix(pipeline): the skip_when AND grammar — the report gate always skipped on a FAIL verdict

## Summary

The skip_when condition grammar only supported the OR form (`A || B`). The eval-omarchy lane's report gate uses the AND form — `@eval.verdict != PASS && @eval.verdict != FAIL` — which was misparsed as ONE comparison against the literal string `PASS && @eval.verdict != FAIL`, so the condition was ALWAYS true: the report/cold-read/render stages ALWAYS skipped, even on a FAIL verdict (the report is supposed to render for a FAILED eval).

- **executor.go — the AND grammar**: `A && B` — both sides true (evaluated before the OR form).
- **and_grammar_test.go** — the unit lock: the gate skips ONLY when the verdict is neither PASS nor FAIL (FAIL → run, NO_VALIDATION → skip, PASS → run).
