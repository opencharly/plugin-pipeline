### The two duplicates, and which copy survives

**`probeResolveChannel` (`probes.go`) — the pre-oracle arm of the `resolve_channel` probe.** It reads
`input["default"]`, the env-selected channel key the probe stopped honouring when it moved to the
oracle's `input["channel"]` and began returning the registry ENTRY as its value. The arm that
`runProbeV` dispatches is `probeResolveChannelV` (`probes.go:112` call site, `:118` definition), and
the surviving copy is authoritative because it is the one on the dispatch path and the one the probe
tests drive. The deleted arm would accept a retired key and return no value at all.

**`lastVerdict` (`agent.go`) — the same backwards transcript scan `runAgentTurns` inlines.** The
shipped budget-exhausted path (`agent.go:63-77`) walks the transcript itself and returns the last
non-empty assistant content; `lastVerdict` walked the same transcript with a DIFFERENT rule (it
demanded a `"verdict"` substring). The inline arm survives: it is what the shipped path executes,
and it is strictly more permissive, so keeping the dead stricter twin could only mislead the next
editor into thinking the gate was narrower than it is.

### The other four

`chatToolCall` (`llm.go`, an unused alias of `llmkit.ToolCall`), `calverRe` (`media.go`, unused —
`mediaDir` takes the calver as a parameter), `resolveTemplate` (`render.go`, unused — nothing reads
`raw["_template"]`), `writeSSEContentThenToolCall` (`sse_test_helpers_test.go`, unused since the
handcrafted SSE client was replaced by the official `openai-go` SDK). Each had zero references in
code, tests and doc comments before deletion.

### The four lint findings that were not dead code

Three `errcheck` findings are `fmt.Fprint*` writes into the SSE test helpers' `http.ResponseWriter` —
a recorder write that cannot fail meaningfully — and become explicit best-effort writes. One
`staticcheck` S1007 is the same `tmplRe` pattern written as a raw string literal, token-identical.
