## Summary

The hard cutover (R5) of the agent stage surface, driven by the eval-omarchy worthless-eval RCA (2026-09-10): the lane's signals were emitted but never consumed as gates, and the agent evidence seam was path-guessing against an undocumented layout (952 failed reads, 4/12 hallucinated reports).

- **Typed outputs**: #AgentStage.outputs is now a typed CUE map (#OutputType: string/int/bool/enum/string_list/object + enum + description). The runner renders the contract into the prompt mechanically and validates the reply at decode; a contract violation fails the stage with the exact field + expected type (the informed redo signal). extractJSON (the quote-unaware scanner that truncated comma-containing prose) is DELETED — the typed decoder is the one canonical impl (R3).
- **Resolved skills**: the env-only mechanism (PIPELINE_SKILLS + PIPELINE_CORPUS_DIR + the hardcoded skillDirs) is DELETED. The entity declares skills.corpus; the stage's skill: refs are SKILL NAMES resolved against it; an unresolvable ref FAILS the stage informatively (the decorative-ref era is gone).
- **Stage-aware ledger tools**: run_outcomes(bed) resolves the latest run dir itself and returns the parsed step outcomes; ledger_facts returns the structured ledger. The raw-path read_summary/read_file tools are DELETED. A read-failure circuit breaker aborts the stage after 5 consecutive tool failures instead of spiraling.
- **Context injection**: the agent user message carries the structured ledger facts — the agent narrates from facts, never from archaeology.
- **Deterministic checks**: the oracle checks render as command steps (check: + id: + command:) — the agent-check prose emission (the verify-with prose, the no-grader-bound SKIPs) is GONE. An assertion-less check is never rendered.
- **The verdict gate**: the ADE stage's fail_on (NO_VALIDATION/SKIP are LANE DEFECTS, not eval outcomes) + the skip_when OR grammar + the sound redo loop (a trigger RESTARTS the chain from the target stage) + the per-stage redo budget.
- **The control bed**: control_bed_template + negate_checks — the negative-control contract (a check that passes without the PR is a FAKE assertion, caught at render).
- **The oracle decides the venue**: resolve_channel takes the oracle's channel key — the env-selected default (EVAL_CHANNEL) is GONE.
- **The ledger-gate**: the deterministic worthless-eval catch (executed_checks from the check-live phase log, control_ok, media_ok).
- **One calver**: currentCalver is YYYY.DDD.HHMM (the day of year), the same scheme the org's check-run stamps its run dirs with — the two-calver lane bug is GONE.
- **The ADE stage runs the DECLARED bed** (the control bed uses the same machinery on its own entity) and destroys the venue after the check-run (the runner never leaves a VM running).
